    - content mit abweichendem etag oder size oder mtime -> stage pending, media_id NULL (neuer Hash nötig, D-02-01), attempts 0

    - Fehler beim Commit -> kein Ack, Unlock nur für die Einträge, die nicht eingetragen wurden
    - Absturz zwischen Commit und Ack (Fake) -> erneute Zustellung trägt idempotent ein (gleicher Endzustand)
    - Antwort mit unbekanntem Feld "path" -> wird verworfen (Modell mit extra="forbid"), Band unlocked, Zähler malformed steigt
