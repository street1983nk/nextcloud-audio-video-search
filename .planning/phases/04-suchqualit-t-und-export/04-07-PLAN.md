    - Zeilenumbruch: wählt die Bruchstelle mit beiden Zeilen <= 42 und kleinstem Längenunterschied, bevorzugt nach Satzzeichen (Test mit festem Satz und erwarteten zwei Zeilen als Literal).
    - Timing: start = erstes Wort.start; end = max(letztes Wort.end, start + 1000, start + ceil(len(text)/20 * 1000)), gedeckelt auf start + 7000 und auf nächster.start - 80; Folge-Starts werden nie verschoben (Synchronität, höchstens Wortzeit).
    - Kurzer Einzel-Cue unter 1 s, dessen Verlängerung kollidiert, wird mit dem vorigen zusammengelegt, wenn die Grenzen es erlauben.
