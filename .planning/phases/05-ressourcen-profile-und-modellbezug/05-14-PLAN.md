## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build -> GitHub-Release | Modelle beim Bau geladen |
| Image -> Laufzeit | Image-Dateien gelten als geprüft erst nach Startprüfung |
| CI-Image vs. Release-Image | Test-Schalter |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-26 | Tampering | manipuliertes Modell im Build | high | mitigate | sha256sum -c je Datei, Build bricht ab; Startprüfung; Smoke-Prüfung im gepushten Digest |
| T-05-27 | Tampering | Test-Schalter im Release-Image (feste Antworten) | high | mitigate | Marker nur per AVS_CI_FIXTURES=1, Standard 0, Workflow-Test, Smoke `test ! -e` |
| T-05-27b | Tampering | Aufräumen löscht falsche Dateien | medium | mitigate | nur Katalognamen unter festen Pfaden, nur nach Image-Bestätigung; Test mit fremder Datei |
| T-05-27c | Repudiation | CC-BY-Pflicht bei Weitergabe im Image | medium | mitigate | NOTICE.models im Image, Smoke prüft |

Offene Threats mit Severity high blockieren den Phasenabschluss.
